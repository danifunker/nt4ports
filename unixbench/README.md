# UnixBench portable harness

Licence: GPL v2, see `LICENSE`. UnixBench itself is at
<https://github.com/kdlucas/byte-unixbench>; this copy of `portable/` also lives in
<https://github.com/danifunker/byte-unixbench>.

`portable/` reads `../src` from UnixBench, so build it inside a UnixBench checkout. See
`portable/README.md`. For PINT, `portable/build-pint.sh`.
