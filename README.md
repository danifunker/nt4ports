# nt4ports

Ports of applications to Windows NT 4.0 on non-x86 CPUs: Alpha, PowerPC and ARM
([PINT](https://github.com/tenox7/PINT), NT 4.0 on the Raspberry Pi).

These are unofficial ports, not from the original authors. Each folder holds patches
and new files, not a copy of the upstream source, under that project's own licence.

| App | Alpha | ARM (PINT) | PowerPC |
|---|---|---|---|
| [7-Zip 9.20](7zip/) | Built and tested | Built, tested in QEMU | Built and tested |
| [Notepad++ 3.3](notepad++/) | Built and tested | Built, tested in QEMU | Built and tested |
| [UnixBench](unixbench/) | Built | Built, tested in QEMU | Built |

Notes for building on PINT are in [pint/](pint/).
